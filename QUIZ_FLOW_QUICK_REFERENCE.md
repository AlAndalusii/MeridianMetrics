# Multi-Scheme Quiz Flow - Quick Reference

## 📊 Quiz Overview
- **Total Questions:** 19
- **Completion Time:** ~3 minutes
- **Schemes Covered:** EPR, PPT, PRN/PERN
- **Lead Qualification:** Automatic scoring + intelligence capture

---

## 🎯 Question Flow Map

```
START
  ↓
[Q1-4] Contact Information (45s)
  ├─ Name
  ├─ Email (validated)
  ├─ Company
  └─ Phone (optional)
  ↓
[Q5-8] Business Profile (45s)
  ├─ Q5: Revenue → Lead qualification
  ├─ Q6: Sector → Priority identification
  ├─ Q7: Packaging volume → Obligation scope
  └─ Q8: Current schemes → **BRANCHING LOGIC**
       ↓
       ├─ "EPR only" → Skip Q12-14 (PPT questions)
       ├─ "PPT only" → Skip Q9-11 (EPR questions)
       └─ "EPR+PPT" or "All three" → All questions
  ↓
[Q9-11] EPR Compliance (30s) *conditional*
  ├─ Q9: Invoice verification → £5K-£15K savings opportunity
  ├─ Q10: Material tracking → System gap detection
  └─ Q11: 2026 modulation → Future cost risk
  ↓
[Q12-14] PPT Compliance (30s) *conditional*
  ├─ Q12: Certificate validity → HMRC penalty risk
  ├─ Q13: Record accessibility → Audit readiness
  └─ Q14: Filing compliance → Deadline tracking
  ↓
[Q15-17] PRN & Intelligence (45s)
  ├─ Q15: PRN strategy → Cost optimization
  ├─ Q16: Biggest pain point → **SERVICE MATCHING**
  └─ Q17: Urgency indicators → **LEAD PRIORITIZATION**
  ↓
[Q18-19] Service & Context (30s)
  ├─ Q18: Service preference → Tier matching
  └─ Q19: Additional context → Critical details
  ↓
RESULTS PAGE
```

## 🎨 Question Types & Purpose

### Contact Questions (Q1-4)
**Type:** Text input
**Purpose:** Lead capture
**Validation:** Email format, UK phone optional
**Skip Logic:** None

### Business Profile (Q5-8)
**Type:** Radio buttons
**Purpose:** Lead qualification + scheme identification
**Key Intelligence:**
- Revenue bracket → Budget indicator
- Sector → Priority scoring
- Volume → Obligation complexity
- Current schemes → Service opportunity

### Compliance Questions (Q9-17)
**Type:** Radio buttons
**Purpose:** Gap detection + value proposition
**Scoring:**
- ✓ Correct = 10 points
- Partial = 5 points
- ✗ Gap = 0 points
- N/A = 10 points (acceptable)

### Service Questions (Q18-19)
**Type:** Radio + Textarea
**Purpose:** Service tier matching + context capture
**No Scoring:** Used for sales qualification only

---

## 🔀 Conditional Logic

### Scheme-Based Skipping:

**If Q8 = "EPR only":**
```
Skip Q12, Q13, Q14 (PPT questions)
→ Jump from Q11 to Q15
```

**If Q8 = "PPT only":**
```
Skip Q9, Q10, Q11 (EPR questions)
→ Jump from Q8 to Q12
```

**If Q8 = "EPR+PPT" or "All three" or "Not sure":**
```
Show all questions Q9-Q17
```
