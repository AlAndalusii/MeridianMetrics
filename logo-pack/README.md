# Meridian Logo Pack

Your complete logo kit — ready to use everywhere.

---

## Folder Structure

```
logo-pack/
├── svg/              ← Scalable vectors (use for print, large formats, editing)
│   ├── meridian-icon-light.svg
│   ├── meridian-icon-dark.svg
│   ├── meridian-modern-light.svg
│   ├── meridian-modern-dark.svg
│   ├── meridian-minimal-light.svg
│   └── meridian-minimal-dark.svg
│
└── png/
    ├── light/        ← Transparent background PNGs
    └── dark/         ← Dark navy background PNGs
```

---

## Which file to use where

| Use Case | Recommended File |
|---|---|
| **Instagram profile picture** | `*_instagram-dp-320x320.png` |
| **Business card** | `*_business-card-500x500.png` or SVG |
| **Website favicon** | `*_32x32.png` or `*_64x64.png` |
| **Email signature** | `*_128x128.png` or `*_256x256.png` |
| **LinkedIn profile / cover** | `*_512x512.png` |
| **Printed materials / high res** | `*_1024x1024.png` or the SVG |
| **Dark website / dark slides** | Use the `-dark` variants |
| **Light website / white background** | Use the `-light` variants |

---

## Logo Variants

- **Icon** — Hexagonal shape with geometric rings. Premium, formal look.
- **Modern** — Rounded square. Clean, tech-forward, app-icon style.
- **Minimal** — Simple hexagon. Best for very small sizes (favicon, watermark).

---

## Tips

- Always use the **SVG** when sending to a printer or designer — it scales to any size without blurring.
- For Instagram, upload the `320x320` version — Instagram displays it at 110px but stores the larger size.
- Business card printers typically need 300 DPI minimum — use the `500x500` PNG or the SVG.
